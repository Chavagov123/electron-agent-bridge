# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, pull requests and discussions; criticise code and
ideas, not people; no harassment, personal attacks or discriminatory language, in any form.

## Reporting

If someone's behaviour in this project's spaces breaks these rules, report it privately to the
maintainer: open a [private report](https://github.com/Chavagov123/electron-agent-bridge/security/advisories/new)
and say in the title that it is a conduct report, not a vulnerability. Reports are read only by the
maintainer and handled confidentially.

The maintainer may edit or remove contributions, and block participants, that break these rules.
