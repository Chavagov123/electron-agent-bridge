# @electron-agent-bridge/engine

[![npm](https://img.shields.io/npm/v/@electron-agent-bridge/engine?label=npm)](https://www.npmjs.com/package/@electron-agent-bridge/engine)

The automation engine of [electron-agent-bridge](https://github.com/Chavagov123/electron-agent-bridge#readme): targets and names, snapshots and deltas,
actions and waits, console and network collectors, state reads, over a Chrome DevTools Protocol
transport. No Electron or Node dependencies. You rarely install it yourself: it comes with [`@electron-agent-bridge/electron`](https://www.npmjs.com/package/@electron-agent-bridge/electron) and [`@electron-agent-bridge/mcp`](https://www.npmjs.com/package/@electron-agent-bridge/mcp).
