# @electron-agent-bridge/core

[![npm](https://img.shields.io/npm/v/@electron-agent-bridge/core/rc?label=npm%40rc)](https://www.npmjs.com/package/@electron-agent-bridge/core)

The protocol of [electron-agent-bridge](https://github.com/Chavagov123/electron-agent-bridge#readme): every method's parameters and results as zod
schemas, error codes, result envelopes with limitations, and the shared budgets, redaction and shape
helpers. You rarely install it yourself: it comes with [`@electron-agent-bridge/electron`](https://www.npmjs.com/package/@electron-agent-bridge/electron) and [`@electron-agent-bridge/mcp`](https://www.npmjs.com/package/@electron-agent-bridge/mcp).
